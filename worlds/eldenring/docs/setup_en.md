# Elden Ring Multiworld Setup Guide

## Required Software

- Elden Ring (Steam)
- The Elden Ring Archipelago randomizer and runtime client

## Installation

1. Install the randomizer following the project README.
2. Generate a randomized game from your options file (`.yaml`).
3. Launch the game through the Elden Ring Archipelago client.

## Joining a Multiworld Game

1. Start the client and connect it to the Archipelago server with your slot name.
2. Load into the game; the client grants received items and reports your checks.

## Hosting / Generating

Fill out an Elden Ring options file and generate as you would for any Archipelago game.
